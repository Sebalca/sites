01 · Fundamentos

O que é o código binário

Binário é um sistema de numeração com apenas dois símbolos: 0 e 1. Cada um chama-se um bit (binary digit). É a linguagem nativa dos computadores porque um circuito eletrónico distingue facilmente dois estados — corrente a passar ou não passar, tensão alta ou baixa — mas tem muito mais dificuldade em distinguir, de forma fiável, dez níveis diferentes de tensão (o que seria preciso para trabalhar diretamente em decimal).

Tudo o que um computador processa — texto, imagens, som, vídeo, instruções — é, no fundo, uma sequência muito longa de 0s e 1s. O que muda entre um ficheiro de texto e uma fotografia não é o "material" (bits), mas a convenção usada para os interpretar.

Porque exatamente dois símbolos e não três ou dez? Não é uma limitação arbitrária — é uma decisão de engenharia: distinguir dois estados é mais barato, mais rápido e muito mais resistente a ruído elétrico do que distinguir vários níveis.

02 · Evolução

Uma linha do tempo

O binário não nasceu com o computador — é uma ideia matemática muito mais antiga que só se tornou tecnologia útil no séc. XX.

séc. II a.C. (aprox.)

Precedentes na Índia e na China

Sistemas de padrões binários aparecem em contextos como a prosódia sânscrita (Pingala) e, mais tarde, no I Ching chinês — sem ligação direta ao binário moderno, mas mostrando que a ideia de "combinações de dois estados" é antiga.

1679

Gottfried Leibniz formaliza a aritmética binária

Leibniz descreve o sistema de numeração de base 2 e as suas operações, influenciado (segundo o próprio) pelo I Ching. Trata-se sobretudo de um exercício matemático/filosófico — ainda sem aplicação tecnológica.

1847

George Boole — a álgebra que dá nome à "lógica booleana"

Boole desenvolve uma álgebra em que as variáveis só podem ter dois valores (verdadeiro/falso). Um século mais tarde, esta é exatamente a matemática usada para desenhar circuitos digitais.

1874

Código Baudot

Émile Baudot cria um código de 5 bits para telegrafia, um dos primeiros sistemas a representar caracteres de texto como padrões binários de largura fixa.

1937–1945

Primeiros computadores eletromecânicos e eletrónicos binários

Claude Shannon (1937) mostra que circuitos com relés podem implementar álgebra booleana. Máquinas como o Atanasoff–Berry Computer e o ENIAC (anos 1940) consolidam o binário como base do cálculo eletrónico.

1963

ASCII

Publicada a primeira versão do American Standard Code for Information Interchange: 7 bits, 128 posições, para uniformizar a troca de texto entre máquinas diferentes.

1991

Unicode

O Consórcio Unicode publica a versão 1.0, com o objetivo de representar, com um único padrão, os caracteres de (idealmente) todas as escritas do mundo — resolvendo a fragmentação de dezenas de codificações regionais incompatíveis entre si.

Datas de invenção de tecnologias antigas têm frequentemente alguma incerteza ou disputa de prioridade entre investigadores — as datas acima seguem os marcos de publicação mais citados.

04 · Representar texto

De letras a bits: ASCII e Unicode

Um computador não "sabe" o que é a letra A — sabe apenas números. A codificação de caracteres é a tabela de correspondência entre número e símbolo. O ASCII (1963) usa 7 bits e cobre 128 caracteres: letras maiúsculas e minúsculas do alfabeto latino, dígitos, pontuação e alguns comandos de controlo — suficiente para inglês, mas não para "ã", "ç" ou "€".

O Unicode resolve esse limite atribuindo um número (code point) a praticamente qualquer caráter usado por qualquer escrita humana — de "A" a "字" a emojis. O UTF-8 é a forma mais comum de guardar esses números em bytes: caracteres ASCII ocupam 1 byte (compatibilidade retroativa total), outros ocupam até 4.

Codificador de texto experimenta

Experimenta escrever "ç" ou "€" e repara que, em UTF-8, esses caracteres ocupam 2 ou 3 bytes — mais do que as letras simples do alfabeto inglês, que ocupam sempre 1.

05 · Outros sistemas de representação

Hexadecimal, Morse e Base64

Binário é fundamental, mas incómodo para humanos lerem — uma cor num website como 11111111 00000000 00000000 é difícil de digerir. Por isso surgiram notações intermédias, feitas para serem mais compactas ou mais robustas a um determinado meio de transmissão.

Hexadecimal base 16

Cada dígito hexadecimal representa exatamente 4 bits (um nibble), o que torna a conversão para/de binário direta — ao contrário do decimal. Por isso é a notação preferida para endereços de memória e cores (#FF9900).

Código Morse áudio / luz

Criado nos anos 1830–40 para o telégrafo elétrico, o Morse não é binário no sentido estrito (usa sinal curto, sinal longo e pausas com durações diferentes), mas partilha a ideia central: representar informação com um alfabeto mínimo de símbolos temporais.

Base64 binário → texto seguro

Muitos sistemas antigos (email, certas partes da web) só garantem transportar texto simples de forma fiável. O Base64 reagrupa os bits de qualquer ficheiro binário em blocos de 6 bits (64 valores possíveis) e mapeia-os para letras, números, + e / — permitindo enviar imagens ou ficheiros dentro de mensagens de texto.

06 · Da máquina ao humano

Níveis de linguagem de programação

Ninguém escreve software real diretamente em 0s e 1s. As linguagens de programação são camadas sucessivas de abstração construídas em cima do binário, cada uma mais próxima da forma como uma pessoa pensa e mais longe da forma como o processador realmente trabalha.

Cada seta neste percurso é executada por outro programa: um compilador ou interpretador traduz o nível de cima para o nível de baixo. É "linguagens" a construir outras linguagens.
